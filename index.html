WordSolve

Load a word list .txt file from your phone (one word per line). It is stored inside the app on this phone. Loading a file with the same name replaces that dictionary.
How to use
Tap the letters bar and type your letters. Use the space bar for a blank. Backspace removes letters. Tap a tile to put the cursor after it, so you can fix or add letters in the middle. The number under a tile fixes that letter to that position in the word (1 = first letter). Leave it empty to let the letter go anywhere. The Enter key runs the search.
